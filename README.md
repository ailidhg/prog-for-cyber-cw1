This project contains a collection of cybersecurity utilities written in Python. It includes a password validator, an IPv4 address validator and a random password generator.

Running this program
1. Ensure Python 3 is installed.
2. Open this branch in Visual Studio Code.
3. Ensure main.py and security_tools.py are in the same folder.
4. Run main.py.
5. Follow the prompts in the terminal.

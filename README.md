Project Overview
This repository contains programs developed for Programming for Cybersecurity Coursework 1.
Each program was written using Python.

Task 1 - Security Tool
A menu-based security tool for user authentication, login attempts, and brute force attack simulation.
• Branch: security-tool

Task 2 - Security Event Logger
A program that records security events, including successful and failed login attempts, with timestamps and event information.
• Branch: security-event-logger

Task 3 - IP Address Validator
A Python program that checks whether an IPv4 address is correctly formatted and contains valid octets.
• Branch: ip-address-validator

Task 4 - Security Incident Manager
A program using Python dictionaries to store, update, and manage security incident information.
• Branch: security-incident-manager

Task 5 - Cyber Security Utilities
A reusable Python module containing password validation, IP address validation, and random password generation functions. The functions are imported and used by a separate main program.
• Branch: cyber-security-utilities

Sources/Technology Used

Running Programs
1. Clone or download this repository
2. Open the relevant task branch
3. Run the relevant Python file using Python 3
For Task 5, run main.py from the same directory as security_tools.py.
